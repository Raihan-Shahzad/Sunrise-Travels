# Sunrise Travels – Next.js 15

A premium, conversion‑focused travel‑agency website built with:

- **Next.js 15 (App Router)**
- **TypeScript**
- **Tailwind CSS**
- **ShadCN UI**
- **Framer Motion**
- **Prisma (SQLite dev / PostgreSQL prod)**
- SEO‑optimized, accessibility‑compliant, Core Web Vitals tuned

## Quick start

```bash
npm i
npx prisma generate    # creates Prisma client
npm run dev            # http://localhost:3000
